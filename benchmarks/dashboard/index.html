Read the boundary first

Comparisons include fresh process launch, key loading, filesystem I/O and the operation. Caches are warm; processes are not. They are not library-only algorithm timings. Security defaults differ; this corpus uses named caller-supplied keys, locally checked reference digests, RSA-2048/SHA-256 and AES-256-GCM.

RSS covers the complete process lifetime. Valgrind allocation and heap measurements are separate from latency, include native libraries, and exclude stacks and non-malloc memory mappings. Shared GitHub runners are noisy. Small sample counts do not establish reliable tail latency or superiority.
